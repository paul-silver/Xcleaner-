# Xcleaner - Take Control of Your X History

Owned by @paul-silver — Paul Silver

Bulk delete posts, reposts & quotes, likes by date range. Secure, fast, with backup.

## Features
- Login via X OAuth
- Pick date range & delete
- Backup before delete (JSON export)
- Freemium: Free 100 deletes/month, then PRO 1000 deletes for $4.99/mo or $19.99/year

## Pricing
- FREE: 100 deletes per month
- PRO: 1000 deletes per month — $4.99/mo or $19.99/year via Paystack
